## Blockers

1. **B1: base vertex applied twice.** `MeshDraw.cpp:327` adds `vertexRange.offset` to every index, and `submitPrimitive` (`MeshDraw.cpp:398`) also passes it as the bgfx start vertex. Every primitive or sprite not at slab offset 0 reads the wrong vertices, possibly past the end. Drop one of the two offsets.
2. **B2: the atlas breaks wrapped UVs and per-image samplers** (`MeshDraw.cpp:525-545`).
   - The shader at `MeshDraw.cpp:48` computes `uv*scale+offset` with no `fract()` and no gutter.
   - REPEAT UVs (the glTF default) sample neighbouring entries.
   - `image.nearest` and `image.clamp` are ignored, and linear filtering bleeds across entries.
   - Atlas only images whose UVs stay in [0,1], or wrap in the shader with padding.
3. **B3: clang-tidy red.** `test/tests/SceneryScaleTests.cpp:10` includes `openrct2-3d/src/GpuBudget.hpp`. The clang-tidy job configures without `-DWITH_TESTS=on`, so that file has no compile-commands entry. Add the flag or exclude `test/`.

## Should fix

4. **S1: view distance is measured from the eye** (`SceneryDraw.cpp:387`; `SceneryChunk.cpp:123-132`; eye set back at `ParkView.cpp:209-225`).
   - At 1080p that is about 20 / 41 / 82 / 164 tiles at zoom 0–3, so toggling 3D from 2D zoom ≥2 shows no scenery.
   - Measure from the look-at ground point instead.
5. **S2: the chunk box Z is fixed at 0..8** (`SceneryDraw.cpp:360-361`), so high terrain is culled wrongly.
6. **S3: the sprite cache does not scale** (`SceneryDraw.cpp:257-306`, `:337-340`).
   - Lookups are a linear search, and sprites are uploaded even for model-backed placements.
   - It never evicts, and it is not cleared on park load.
7. **S4: LRU cost and a soft budget** (`GpuBudget.cpp:204-230`; `SceneryDraw.cpp:480-502`).
   - Evict is O(items × pinned): 909 ms with 3000 items and a 40k pinned list.
   - The budget is not enforced when the visible set is over budget.
   - PNG bytes are counted against the GPU budget.
   - Atlas space is never freed.
8. **S5: a failed upload is sticky.** `SceneryDraw.cpp:520` stores `-1`, and the type is never retried.
9. **S6: `ModelLoadQueue` lifetime** (`ModelLoadQueue.cpp:48-60`, `:150-160`).
   - The destructor drains the queue: 2 s for 1000 × 2 ms loads.
   - A `forget()` issued while a load is in flight is undone.
   - `takeReady` is O(n).
10. **S7: no per-frame budget for chunk rebuilds** (`SceneryDraw.cpp:459-470`).
    - After a load, the whole map rebuilds in one frame.
    - Running rides dirty chunks almost every frame.
    - Log lines at `SceneryDraw.cpp:473` print every frame.
11. **S8: startup scaling.**
    - `streamingChecksumOk` (`ModelCache.cpp:771-822`) re-reads and re-hashes every cache body on every launch, about 10 GB at 10k × 1 MB.
    - Caches store both PNG and RGBA (`ModelCache.cpp:302-313`).
    - An mtime-only change hashes the file twice (`ModelCache.cpp:650-700`).

## Nits

12. `readCache` makes two stat calls on the in-game path, with a TOCTOU gap (`ModelCache.cpp:370-372`).
13. `_validated` lookups are case-sensitive (`ModelCache.cpp:952`, `:979`), while duplicates and cache paths are case-folded.
14. Frustum near/far planes assume a −1..1 depth range (`SceneryChunk.cpp`). This is conservative on 0..1 backends.
15. A partially uploaded model is accepted, and `_models` ids are never reused (`MeshDraw.cpp:496-507`).
16. The handle cap keeps a fixed slack of 8 (`MeshDraw.cpp:121-132`).
17. `composeVisible` calls `_loads->phase()` per placement per frame while a type is loading (`SceneryDraw.cpp:575`).
18. `kMaxCacheReadBytes` (64 MB) is below the RGBA size of a 4 × 2048² model (`ModelCache.cpp:371`).
